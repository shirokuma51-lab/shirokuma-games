# 忘れんぼうダンジョン — 3Dベータ版

ミニチュア風の地下迷路を探索するブラウザーゲームです。バランス調整中です。

## 遊び方
- PC: 矢印 / WASDで移動、E / Spaceで調べる、Mで地図、Escで休憩。
- スマホ: 左下のジョイスティックと各ボタンを使います。
- メモは次の階のヒント。解読内容は記録されません。
- 扉で能力を覚える・交換する・覚えず進むことを選べます。能力は最大4つ。
- ハートは3つ。ハンバーガーで1回復。お化けは決まった道を巡回します。
- 階の入口で自動保存。同じブラウザーで続けられます。現在の階の途中状態は保存しません。
- あきらめるかハートが0になると結果を共有できます。

## 構成
core.js: 乱数・迷路・能力・暗号。view.js: Three.js描画・円状の光・固定方向の追従カメラ。game.js: 操作・UI・保存・結果共有。
three.bundle.js: Three.js r180。ライセンスはTHREE-LICENSE.txt。

## 検証と制限
生成2560盤面、能力交換・回復・カウンター・保存・結果共有とPC/スマホ幅のChrome表示を検証しました。500盤面の比較で行き止まりは約81%減少しました。
実機の性能やタッチ操作は端末により異なります。WebGL対応ブラウザーが必要です。保存はこの端末・ブラウザー内だけで、消去すると復元できません。旧試作版からの保存引き継ぎはありません。
